Historical web classification regression: 4472/5146 → 4664/5146 (86.90% → 90.63%); 241 corrected, 49 regressed. Not a fresh blind field test.

Same classifier, different capture tools / 同版分類器，取景工具仍不同

Android uses optional EfficientSAM-Ti point selection; web SAM outlines can differ. Android does not include automatic tree detection, panorama reprojection or point-cloud fusion.
安卓可手動點選樹木並用 EfficientSAM-Ti 建議遮罩，但與網頁 SAM 輪廓可能不同；安卓尚無自動找樹、全景透視校正或點雲融合。
