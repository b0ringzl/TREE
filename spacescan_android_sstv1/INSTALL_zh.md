# 安装与验收：SSTv1 完全离线版

## 需要复制到手机的两个文件

1. `SpaceScan-Trees-SSTv1-v0.2.apk`：应用安装包。
2. `SSTv1-20260918-Offline-Model.zip`：约 2.53 GB 的离线模型包。**不要解压**，放在手机 Download/下载目录。

建议用 USB 复制大文件。准备至少 6 GB 可用存储空间，推荐 8 GB；16 GB 运行内存不是剩余存储空间。

## 操作步骤

1. 安装新版 APK（与原版包名/签名一致，可覆盖升级；先导出重要历史记录）。仅为本次安装允许所用文件管理器安装本地 APK。
2. 打开 SpaceScan Trees，点击 **Import SSTv1 model / 匯入 SSTv1 模型包**。
3. 在系统文件选择器中选择上面的 ZIP，等待校验和离线自检完成。首次导入耗时取决于手机存储速度，期间保持应用在前景。
4. 选择照片，必要时用 **Polygon crop / 多邊形裁剪** 确认目标，再点击 **Identify tree / 辨識樹木**。
5. 关闭 Wi-Fi 和移动数据，重复识别以确认完全离线运行。

导入成功只需做一次。不要选择旧版 YOLO 模型或解压后的单个 ONNX 文件。校验不符时应用会拒绝激活，不会自动回退到旧模型。已经完整导入后无需重复导入。

## 这次请重点验收

使用 `微信图片_20260916084639_130_2.jpg` 原文件，不裁剪先识别：应重点检查第一候选是否为 **Terminalia mantaly / 小葉欖仁**。安卓模拟器已复现第一候选正确，模型分数约 34.8%，不是 34.8% 准确率，也不保证每台手机小数完全一致。

再测试你常用的土沉香、白桂木照片，以及手动裁剪、历史记录与结果导出。如遇错误，请导出 JSON，记录手机型号、运行时间、原图及是否裁剪。不要仅凭某次置信度更高认定准确率提高。

新版同步的是桌面同版 **148 类图像分类模型**，不是所有桌面功能：尚无自动单木检测、全景透视校正、点云融合。多树照片/全景请手动裁剪；与桌面比较时必须选取同一目标与同一裁片。

旧版 APK 和源码仍保存在原交付文件夹，没有被覆盖。Android 手动降级到旧版可能要求卸载新版，卸载会删除应用内历史记录及导入模型，故回退前先导出所需记录。桌面 Demo 完全未改动。
