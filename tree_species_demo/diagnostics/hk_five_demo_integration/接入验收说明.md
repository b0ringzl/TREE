# 香港扩展五类 Demo 接入验收

## 已完成

新增可选实验域 hongkong_vmms_five，真实调用 reviewed_five_species_pilot_v1_20260907/model.joblib 中的图像、点云、融合分类头。旧武汉、香港通用及香港街景三类模型入口保持可用，原权重、训练审核和点云资产内容未改变。实验权重以独立模式挂载到 Demo，不是替换默认模型或宣称正式生产上线。

入口：http://127.0.0.1:8037/?domain=hongkong_vmms_five

1. 选择五类模式。
2. 上传图像、点云，或确认同木后上传双源；也可选择示例及输入模式，点击“运行示例”。
3. 查看主候选、分源 Top-3、输入质量和依据；可导出 JSON。

## 关键行为

- 凤凰木、银合欢可推理，但明确标注独立评估缺失，不因这项研究限制禁用实验入口。
- 双源必须确认同木且两源未严重低质才计算融合。主结果采用图像优先，不用融合分数强制覆盖；同木分源首选冲突时提示复核。
- 五类使用与训练一致的稀疏点处理：1081 点仍以 1081 点编码，不复制凑够 2048；原武汉及香港三类的采样方式保持不变。
- 每类一个内置示例，按固定 ID、优先留出规则选取，不按预测对错筛选。凤凰木和银合欢明确为训练示例，其余为小留出示例。
- 结果依据为模型特征来源、候选差值、几何质检和模态一致性，不伪造叶片/花果特征解释。
- 所有未知阈值和质量降级规则是未独立验证的演示策略；这些功能测试不改变此前精度报告。

## 验证结果

36 项单元与原验收接口回归测试通过。

真实 HTTP 和模型调用：

- 五类 × 图像/点云/双源，共 15 次示例调用全部正常返回。
- 检查未配对、全黑图像、平面点云、缺少输入、损坏点云等异常情形。
- 验证文件名不会改变分类结果，1081 点稀疏样本不被填充。
- 原武汉、香港通用图像、香港街景三类均成功运行示例回归。
- 核验受保护的审核与编码器/实验模型文件内容不变；未提交任何真实验收决定。

浏览器中实际加载新入口，确认四种模型域选项、五个示例、训练/留出标记、上传入口及输入模式控件正常出现。此项是页面装载检查；完整输入分支通过上述真实 HTTP 测试验收，不把它表述为全部浏览器点击流程已自动化验收。

自动验证记录：`http_verification.json`。复现命令（在 yolo 环境运行）：`python tree_species_demo/verify_five_demo_http.py`。

## 未完成的范围

本版是已有本地项目上的可运行研究 Demo，不是独立安装包或公网部署。仍需整个 TREE 项目与现有 Python 环境。未实现全景多树自动检测，也未证明扩展五类的现场识别准确率或未知拒识可靠性；点云垂直跨度不当作完整树高。

科研灵感：分源候选与输入质量的显式展示可用于收集模态冲突反馈，为后续验证质量感知融合提供可追溯样本，而不能单凭功能接入宣称融合收益。
