# 树识 — 本地图像与点云识别 Demo

双击 `启动树种识别Demo.cmd`，打开 http://127.0.0.1:8037 。使用项目现有 yolo Python 环境与权重，无需重新训练。整个 TREE 项目目录和本机 miniconda 环境需要保留；本demo不是独立可迁移安装包。

## 香港扩展五类已接入（2026-09-07）

直接打开 http://127.0.0.1:8037/?domain=hongkong_vmms_five ，或在“模型范围”选择“香港扩展五类 · 图像 / 点云 / 双源 · 实验”。包括凤凰木、石栗、银合欢、大叶合欢、南洋杉（原训练合并类），与香港原三类、通用图像和武汉入口独立并存；没有合成统一八类分类器，也没有覆盖旧权重。

可上传单木图像、点云或同木双源，或从五个内置示例中选择并点击“运行示例”。示例每类按固定 ID 选择，优先小留出样本，不按预测正确与否挑选；凤凰木和银合欢是训练示例，页面明确标注“不是测试集”。所有参考标签在模型推理后才附加。

本模式调用本轮已训练的三个分类头以及冻结 YOLO / WHU PTv2 编码器。点云最多使用 2048 个真实独立点，少于上限不复制补齐，和训练输入处理保持一致。凤凰木与银合欢点云可靠性尚未独立验证，但可运行并查看候选。

结果以图像优先；图像严重低质时可用点云候选退回；同木图像与点云首选冲突时提示复核。融合分支在配对确认且输入通过启发式质检时单独计算和展示，不自动覆盖主结果。这是演示策略，不是已经验证的融合性能提升。五类分数不是校准置信度，0.55 分数 / 0.15 间隔拒识仍是未验证启发式；本模块不生成植物学真值解释或可靠整树高。

前端“树种与测试数据”页含五类清单及实验报告；识别后可导出 JSON。五类例图和点云通过 `/hk-five-sample-file/{sample_id}/image.jpg`、`point.npz` 读取。详情见 `diagnostics/hk_five_demo_integration/接入验收说明.md`。

## 原有模型和通用输入

选择香港或武汉范围，上传一棵树的图像和/或点云。武汉双源需确认同木配对。支持 JPG/PNG/WEBP 与 NPZ/NPY/XYZ/TXT/CSV/LAS/LAZ；文本点云前三列为XYZ、无表头，Z轴朝上，LAS/LAZ应预先提取单木，LAZ还需环境有相应解码后端。NPZ键为points_xyz、points或xyz，不读取class_index等真值信息。单文件限80MB。

香港19类来自148类全量YOLO模型验证集的F1排名（每类至少10例），保留原始完整softmax，不对所选19类重新归一化。未知采用范围、分数、候选间隔和质量拒识。香港仅图像有这些类的已训练权重；点云返回质检和未知，不能用于这些类融合。

武汉原始YOLO/PTv2/TSCMDL融合模型包含18类，按融合验证F1选17类；排除樟（该验证集融合F1最低）。18维原模型保持原样，预测到排除类会进入未知，不改写成其他已知树。详细映射及理由见树种列表与测试说明.md。

未知不是训练好的神经网络类别。分数0.55、间隔0.15、清晰度和曝光阈值为演示启发式，未经独立开放集校准，不能保证范围外输入都被拒识。香港网络图像验证表现不代表街景实测准确率。原训练合并类别继续保留，中文名仅为展示参考。

推理依据包括原始候选分数、图像中心裁剪3×3遮挡敏感图、点云独立点数/高宽比和模态一致性。遮挡图不是植物学证据。点云从头计算特征；融合使用训练好的特征投影和分类头，而非查表。测试真值仅在推理完成后附加对照。

测试数据集.zip / test_data 含质量筛选的已留出测试样本、配对点云以及范围外/人工退化测试。按曝光、清晰度和配对可见比例选样，不按模型预测对错选样。来源及哈希见samples.json。这个经过筛选的小子集用于操作验收，不能作为整体泛化指标。

服务默认只监听127.0.0.1，不向互联网传输上传文件。不改动原标注软件、源数据或模型。上传只在内存处理；模型仅从受信任项目路径加载，用户NPZ/NPY使用allow_pickle=False。

重新生成测试包：`python prepare.py`。启动服务：`python server.py`。API文档：http://127.0.0.1:8037/docs 。
