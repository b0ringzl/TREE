## 穷尽式树冠候选审计

使用既有 642 帧、905 个人工实例进行反向审计：

- IoU ≥ 0.20 的候选召回：97.35%（881/905），适合作为可编辑草稿。
- IoU ≥ 0.50 的候选召回：90.28%（817/905）。
- 160 个人工空帧上产生 416 个额外候选，说明高召回策略会带来误检，必须验收。

## 树种证据与降级规则

政府树木清单投影经全景方位角校准后，在与人工标注匹配的已知实例上总体一致率仍只有 24.78%。分层结果为：

- 高置信：11/13（84.62%）——保留为待验收预标注。
- 中置信：8/26（30.77%）——正式类别降为待定，只保留候选证据。
- 低置信：9/74（12.16%）——正式类别降为待定，只保留候选证据。

现有网页图像 YOLO 分类器在街景树冠上的一致率仅 0.79%，没有用于正式定类。

另用 905 个香港街景人工实例建立 15 类域内 YOLO11s 分类器；训练/验证按整段路线块隔离：667 个训练裁剪、203 个验证裁剪。验证 Top-1 为 64.53%，置信度 ≥ 0.99 时选择性准确率为 84.54%。它给 4,049 个非人工实例写入了候选 Top-5，但没有改动任何正式类别。政府清单与域内模型一致的案例会在逐实例队列中单独标记，仍需人工接受。

## 在线依据

树木位置与物种属性来自香港政府 CSDI 的 [路政署 Tree 数据集](https://portal.csdi.gov.hk/csdi-webpage/dataset/hyd_rcd_1632210213867_60179) 和 [康文署大型公园 Trees 数据集](https://portal.csdi.gov.hk/csdi-webpage/dataset/lcsd_rcd_1730101435734_98947)。学名、异名和香港植物图像参考使用[香港植物标本室植物资料库](https://www.herbarium.gov.hk/sc/hk-plant-database/index.html)。

Pl@ntNet 官方识别 API 需要私有 API key，因此本轮没有伪造或绕过其在线识别结果；当前在线证据均保留 URL、政府树木编号、距离和投影误差供验收追溯。

## 验收入口

1. 双击项目根目录的 `启动VMMS树种预标注验收工具.cmd`，进入可编辑验收界面；`review.html` 可继续用于全局筛选和只读浏览。
2. 刷新页面后，点击画面中的树冠或右侧树木卡片，在“编辑所选树木 → 树种”下拉框中修改类别；每棵树已预填，证据等级、模型分数和冲突信息写在备注中。
3. 如列表没有所需类别，在自定义树种框输入“拉丁名 中文名”并添加。
4. 点击“保存有树标注并下一帧”才算正式接受；也可删除误检、修改轮廓或标记为无树/不可用。
5. 优先检查备注为 `助手预标[low]` 的实例，再检查 `助手预标[medium]`；`high` 项可快速抽查。
6. 完成验收后再生成按路线块/单木轨迹隔离的 train/val/test；当前目录已放置 `DRAFT_NOT_FOR_TRAINING.txt` 防止误用。
