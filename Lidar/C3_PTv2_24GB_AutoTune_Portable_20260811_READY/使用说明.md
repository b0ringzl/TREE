# C3 PTv2 24GB 自动调优便携训练包

本文件夹包含完整训练输入、kNN 缓存、模型代码、Windows CUDA 运行环境、实时监控和结果打包工具。目标电脑不需要安装 Conda，也不需要了解原项目。

## 使用前

1. 将整个 `C3_PTv2_24GB_AutoTune_Portable_20260811_READY` 文件夹通过 U 盘复制到目标电脑的本地 SSD。
2. 不要直接在 U 盘上训练。
3. 连接电源，保持电脑散热正常，不要合上笔记本屏幕或手动执行睡眠/关机。
4. 目标电脑需要 64 位 Windows、可正常工作的 NVIDIA 驱动和至少 20 GiB 可用显存。
5. 首次启动建议预留至少 15 GiB 额外磁盘空间，用于解压环境、自动调优和三个训练结果。

## 一键启动

双击 `START_C3_TRAINING.bat`。

首次运行会自动完成：

- 解压随包运行环境；
- 校验 U 盘复制后的文件完整性；
- 检查 CUDA、GPU、数据集和 kNN 缓存；
- 使用真实训练步骤测试 `batch=40/48/56/64`；
- 按每秒处理样本数选择最快且满足显存安全阈值的 batch；
- 将所选 batch 锁定给三个随机种子；
- 从零开始依次训练三个随机种子；
- 打开实时监控窗口。

自动调优一般需要数分钟。它只在首次启动时执行一次，以后断点恢复不会改变 batch。

## 显卡利用与亮屏

- 训练代码已启用 AMP、矩阵乘法高精度优化、cuDNN benchmark 和适用硬件上的 TF32。
- 自动调优以真实吞吐量为准，不以“显存占满”为目标；显存过满反而可能降低速度或导致训练中断。
- 训练阶段 GPU 利用率通常应接近 95%-100%。验证、保存检查点和切换随机种子时短暂下降是正常现象。
- `keep_awake.ps1` 会在环境检查、自动调优和训练期间持续阻止 Windows 关闭显示器或进入系统睡眠。
- 关闭监控窗口不会停止训练，也不会关闭训练用亮屏守护。
- 亮屏守护不能阻止手动睡眠、手动关机、合盖动作或管理员强制安全策略。

监控窗口中的以下文字表示亮屏生效：

```text
Awake    : active (display and system sleep blocked)
```

## 训练配置

- 随机种子：`20260728`、`20260729`、`20260730`
- 最大轮数：120
- Early stopping patience：20
- 验证 batch：64
- AMP：开启
- 每个随机种子都从零开始
- 若中断，只允许同一随机种子从自己的 `last.pt` 恢复

自动调优结果保存在：

```text
diagnostics\auto_tune_report.json
```

## 监控与断点恢复

- 双击 `MONITOR_C3.bat` 可重新打开监控。
- 关闭监控窗口不会终止训练。
- 需要暂停时，双击 `PAUSE_AFTER_CURRENT_EPOCH.bat`。程序会完成当前 epoch、验证和检查点保存后安全暂停，不会继续下一个随机种子。
- 需要恢复时，双击 `RESUME_C3_TRAINING.bat`。程序会从最近完整的 `last.pt` 继续，并重新启用亮屏守护。
- 电脑重启或训练异常退出后，也可以双击 `RESUME_C3_TRAINING.bat` 恢复。
- 暂停脚本不会立即强杀训练，因此当前 epoch 较长时需要等待一段时间。

训练结果位于：

```text
output\runs\seed_20260728
output\runs\seed_20260729
output\runs\seed_20260730
```

## 把结果带回本机

全部训练结束后，双击 `PACK_C3_RESULTS.bat`。程序会在当前文件夹生成：

```text
C3_RESULTS_日期时间.zip
```

只需要通过 U 盘把该 ZIP 文件复制回本机，不必再次复制完整训练包。
