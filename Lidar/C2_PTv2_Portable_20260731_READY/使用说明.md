# C2 PTv2 单文件夹迁移训练包

## 使用条件

- 目标电脑必须是 64 位 Windows 10/11。
- 必须有 NVIDIA GPU；建议显存不少于 8 GiB。
- 必须先安装可正常运行 `nvidia-smi` 的 NVIDIA 驱动。
- 复制完成后建议目标磁盘至少还有 16 GiB 可用空间。
- 不要求安装 Python、Conda、CUDA Toolkit 或本项目源码。
- 不要求联网，Python、PyTorch 和 CUDA 12.8 运行时已在本文件夹内。

## 使用方法

1. 用 U 盘复制整个文件夹，不要只复制其中一部分。
2. 建议把整个文件夹复制到目标电脑的本地 SSD；不要直接在慢速 U 盘上训练。
3. 双击 `START_TRAINING.bat`。
4. 首次运行会解包环境、校验 U 盘传输完整性、检测 GPU，然后自动续训。
5. 启动窗口随后显示实时进度。关闭监控窗口不会停止后台训练。
6. 之后可双击 `MONITOR_ONLY.bat` 再次查看。

## 24GB 显存模式

- 普通启动保持原实验的 batch size 16。
- 对于 24GB 或更高显存的 NVIDIA GPU，可双击
  `START_TRAINING_24GB.bat`。
- 如果训练正在进行，脚本会等待当前轮次保存完整断点，再切换进程。
- 脚本会用真实数据依次探测 batch size 48、40、32，并自动采用能稳定
  运行的最大值。
- 模型权重、优化器、学习率调度器和已有历史会继续使用，不会重新训练。
- 改变 batch size 会改变后续每轮的优化步数，因此高显存模式属于加速续训，
  不再与 batch size 16 的实验严格逐步等价。

## 文件布局

- `input/dataset`：17,134 株点云及 19 类清单。
- `input/knn_cache`：PTv2 所需的 8 邻居缓存。
- `input/checkpoint`：从原电脑迁移时锁定的训练断点。
- `app`：训练和监控代码。
- `runtime`：已验证的 Windows Python/PyTorch 环境压缩包。
- `output/run`：目标电脑上的所有训练输出、权重、历史和图表。
- `diagnostics`：文件完整性及设备检查报告。

输入、环境和输出全部位于本文件夹，不会依赖原电脑的 `D:\TREE` 路径。

## 训练设置

- 最大 120 轮，early stopping patience 20。
- 默认 batch size 16，验证 batch size 16；24GB 模式会自动探测更大值。
- AdamW，初始学习率 0.001，最低学习率 0.00001。
- AMP 混合精度，随机种子 20260731。
- 从迁移包内的 `last.pt` 继续，不重新开始。
- 官方测试集只在验证集选出的最佳模型锁定后读取。

## 注意

- 迁移后不要同时让两台电脑继续这同一个实验，否则会形成两个不同分支。
- 如果目标 GPU 仍然显存不足，启动检查会明确报错，不会静默改动 batch。
- 将已经解包过 `runtime/env` 的文件夹再次移动可能破坏环境。应先确定最终
  SSD 位置，再首次运行。
