# E1 四分类多模态识别验收应用阶段报告

完成时间：2026-08-23

## 阶段状态

E1 已完成。论文 D3 工作按用户要求暂停，本阶段转向本地识别应用，不启动训练、不修改模型权重，也不覆盖原有 D1/D2 质检工具。

## 应用定位

本阶段交付的是“四分类验证样本验收版”，用于在同一页面检查单影像、单点云和图像-点云融合三个方向的冻结预测结果。它读取 D1 正式验证集与测试集的三个随机种子概率并求平均，不在页面访问时重新训练或重新选择模型。

- 地址：`http://127.0.0.1:8771/`
- 样本：241 株，其中验证集 90 株、测试集 151 株。
- 类别：`Cinnamomum camphora`、`Lagerstroemia indica`、`Magnolia grandiflora`、`Other`。
- 预测：ResNet50 单影像、PTv2 单点云、TSCMDL 融合。
- 质量信息：D1 自动影像风险 + D2f 用户点云完整度/纯度复核。

## 已实现功能

1. 并排展示配对影像和单树点云四视图。
2. 显示三种模型的集成预测、置信度和全部类别概率。
3. 按验证/测试划分、参考树种、影像质量和三模态关系筛选。
4. 支持查找 sample key、tree ID 和道路编号。
5. 支持“验收模式”显示或隐藏参考标签与预测对错。
6. 展示自动影像风险和已完成的点云人工质量结论。
7. 给出质量感知候选输出，并在模态分歧或输入质量不可靠时标记人工复核。

## 冻结结果

三随机种子概率集成在 241 株正式样本上的结果为：

| 方向 | Accuracy |
|---|---:|
| 单影像 | 80.50% |
| 单点云 | 87.97% |
| 融合 | 88.80% |
| 规则型质量感知候选 | 88.38% |

质量感知候选规则的总体准确率没有超过原融合模型，因此当前只作为应用交互和路由机制原型，不能宣称为精度提升方法，也不能替代后续独立校准。

## 样本关系

- 三模态预测一致：194 株。
- 点云与融合正确、单影像错误：23 株，归入“点云挽回图像错误”。
- 单点云正确但融合错误：6 株，归入“负迁移”。
- 融合正确而图像、点云均错误：1 株。
- 其他预测分歧：17 株。
- 自动影像风险：18 株。
- 点云总体可用性：通过 214 株、谨慎可用 25 株、不通过 2 株。

## 边界

当前版本不接受任意外部文件上传，因为真正的现场识别还需要把图像裁剪、单树点云分割、点数采样、坐标归一化和图像-点云配对全部固化为在线预处理协议。直接给页面增加上传按钮但不约束这些步骤，会产生看似可用但不可复现的结果。
