# A4 全景投影原型与小样本配对质检阶段报告

日期：2026-07-14

## 1. 阶段范围

本阶段只完成全景图投影原型与小样本配对质检，没有开始 B1 数据集批量构建，也没有训练任何模型。原始 WHU-STree 点云、轨迹和全景图均按只读输入处理。

## 2. 实现内容

1. 新增轨迹读取、朝向列诊断、最近相机位姿筛选、等距柱状全景投影和跨接缝最小包围区间计算。
2. 依据相邻相机轨迹方位角诊断 `traj.csv` 的三个朝向列。第三列与行进方向的中位绝对差为 0.2921 度，明显优于前两列，因此本原型按 `roll, pitch, heading` 解释。
3. 使用坐标约定：局部 X 向右/东、Y 向前/北、Z 向上；heading 从 +Y 顺时针增加；全景图中心列对应相机前方。
4. 为 A3 的 4 棵样例树各选取 2 个最近全景视角，输出论文图像分支所需尺寸的 768x512 原始裁剪、红色点云叠加图和全景定位预览。
5. 投影裁剪支持全景图左右接缝；垂直方向采用 0.5% 至 99.5% 分位数抑制极少量离群点。

## 5. 已知风险

1. 本地公开数据包未提供完整的相机杆臂和精确外参模型，因此当前结果是粗投影，不等同于论文内部标定精度。
2. README 对朝向列的文字顺序与轨迹方位诊断不一致；当前 `roll, pitch, heading` 是基于运动轨迹的实证推断，应在更多道路上继续抽检。
3. “最近相机”不必然是可见性最佳视角。邻树遮挡、树冠交叠、车辆和建筑背景都可能降低图像分支样本质量。
4. 树 3963 说明几何投影正确不代表图像裁剪天然纯净。B1 必须引入自动指标和人工抽检，不能把所有最近视角无筛选纳入训练。
5. A3 样本中的 raw label 29 被保留并映射为 benchmark class 18（Others）；该样本只用于投影验证，不应混入后续三类共有树种训练。
