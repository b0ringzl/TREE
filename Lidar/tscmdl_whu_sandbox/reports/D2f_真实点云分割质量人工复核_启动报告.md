# D2f 真实点云分割质量人工复核启动报告

启动日期：2026-08-21

## 一、阶段目标

在 D2e 合成消融之后，使用真实单树点云中的自然质量差异进行外部验证：由人工独立评价点云空间完整度、分割纯度和总体可用性，再检验这些质量等级是否与冻结单点云及融合模型的分类正确率、真实类别概率相关。

本阶段不训练或微调模型。

## 二、样本范围

- 纳入 D1 四分类全部模型未见样本，不再人工挑选论文案例。
- 验证集 90 株、测试集 151 株，共 241 株。
- 香樟 72 株、紫薇 51 株、广玉兰 67 株、Other 51 株。
- 覆盖 31 条道路。
- 单影像、单点云、融合三套三随机种子预测均已绑定到隐藏分析字段。
- 人工复核界面不显示预测类别、正确性、置信度或模型风险，避免结果知情偏倚。

## 三、关键解释边界

当前点云来自 WHU-STree 的真实 `tree ID` 提取，不是自动单树分割模型输出。因此本阶段能够检验“真实点云样本中自然存在的截断、稀疏、离群或疑似混入是否关联分类性能”，不能直接报告为“自动分割算法精度对分类的影响”。

D2e 提供受控因果证据，D2f 提供真实样本关联证据；二者联合使用比单独使用任何一个阶段更稳妥。

## 四、人工标注字段

- 空间完整度：完整、轻微缺失、中度缺失、严重缺失、无法判断。
- 分割纯度：干净、轻微混入、中度混入、严重混入、无法判断。
- 总体可用性：通过、谨慎可用、不通过。
- 问题类型：树冠截断、树干缺失、单侧缺失、整体稀疏、结构破碎、邻树混入、地面/背景混入、离群点及其他。
- 判断置信度：高、中、低。
- 自由备注。

## 五、自动指标

对 241 株点云计算了原始点数、独立采样点数、重复采样比例、三轴稳健跨度、PCA 形状描述、最近邻间距、离群点比例、垂直/水平方向覆盖和体素占用率。

这些指标仅用于筛选和后续校准，不作为真实质量标签。自动风险排序按固定规则生成，复核对象仍是 241 株全量样本，因此不会重复 D2a 中树种和道路过度集中的抽样问题。

## 六、复核工具

- 访问地址：`http://127.0.0.1:8770/`
- 启动入口：`Lidar/tscmdl_whu_sandbox/启动D2f真实点云质检.bat`
- 停止入口：`Lidar/tscmdl_whu_sandbox/停止D2f真实点云质检.bat`
- 页面显示点云正视、侧视、俯视、立体视图及配对影像。
- 人工结果逐条原子写入 `review_state.json`，刷新页面或重启服务不会丢失。

## 七、当前验收

- 241 / 241 个样本键唯一。
- 90 个验证样本与 151 个测试样本全部纳入。
- 241 对影像与点云资产均存在。
- 全部点云数组格式有效。
- 每株均绑定单影像、单点云和融合三套集成预测。
- 质检 UI 不返回隐藏模型结果。

## 八、完成人工复核后的分析

1. 锁定人工复核文件及 SHA-256。
2. 统计完整度、纯度及问题类型的分布和道路/树种覆盖。
3. 分别在验证集和测试集比较不同质量等级的单点云与融合准确率、Macro-F1 和真实类别概率。
4. 使用树级 Bootstrap 置信区间和预先定义的趋势检验；必要时控制树种、道路和原始点数。
5. 检验真实数据方向是否与 D2e 的空间完整度、纯度剂量响应一致。
6. 输出论文可用图表，并明确区分受控因果证据与真实样本关联证据。
