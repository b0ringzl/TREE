# C3 24GB 自动调优、亮屏与暂停恢复迁移包阶段报告

## 1. 阶段目标

为 24 GB NVIDIA GPU 训练机准备一套完整、独立、可通过 U 盘迁移的 C3 PTv2 三随机种子训练包。目标机无需 Conda 和原项目经验，复制整个文件夹到本地 SSD 后即可一键启动。

本阶段在原三随机种子迁移包基础上新增三项能力：真实吞吐量自动调优、训练期间保持亮屏、按完整 epoch 安全暂停与断点恢复。

## 2. 交付位置

`D:\TREE\Lidar\C3_PTv2_24GB_AutoTune_Portable_20260811_READY`

迁移包包含 17,134 个点云样本、19 个类别、kNN 缓存、PTv2 代码、便携式 CUDA/Python 运行环境、训练脚本、监控脚本和结果打包工具。不可变文件清单共 17,180 个文件，合计 9,368,347,004 字节，完整 SHA-256 复核通过。

## 3. GPU 自动调优

首次启动会在目标 GPU 上依次实测 `batch=40/48/56/64`。每个候选都执行真实的前向、反向和优化器步骤，按照每秒处理样本数选择最快方案，同时剔除 PyTorch 峰值显存超过总显存 82% 的候选。

这种方法的重点是获得最高训练吞吐量，而不是人为把 24 GB 显存全部占满。实际 batch 只有在目标机运行后才能确定，选定后会固定用于三个随机种子，断点恢复也不会重新改变。

## 4. 保持亮屏

`keep_awake.ps1` 使用 Windows `SetThreadExecutionState`，在环境准备、设备检查、自动调优和正式训练期间阻止显示器自动关闭及系统自动睡眠。守护进程跟随启动器或训练进程生命周期，训练结束后自动退出并恢复系统原有电源策略。

该功能不会覆盖用户手动睡眠、手动关机、合盖动作或管理员强制策略，因此目标机仍需接通电源、保持散热并避免合盖。

## 5. 安全暂停与恢复

- `PAUSE_AFTER_CURRENT_EPOCH.bat`：写入暂停请求，等待当前 epoch 的训练、验证、`last.pt` 和历史记录全部保存后退出；不会强杀 Python 进程，也不会继续下一个随机种子。
- `RESUME_C3_TRAINING.bat`：清除已完成的旧暂停请求，检测当前 seed 的 `last.pt`，通过 `--resume` 从最近完整 epoch 继续，并重新启用亮屏守护。
- 暂停不是瞬时操作。若当前 epoch 尚未结束，暂停窗口会继续等待，直至训练器写入安全暂停确认。
- 关闭实时监控窗口不会暂停或停止训练。

## 7. 使用顺序

1. 将整个迁移包复制到目标电脑本地 SSD，不能直接在 U 盘上训练。
2. 双击 `START_C3_TRAINING.bat`，等待环境准备、完整性校验和自动调优完成。
3. 使用 `MONITOR_C3.bat` 查看实时训练进度。
4. 需要暂时停机时，双击 `PAUSE_AFTER_CURRENT_EPOCH.bat` 并等待安全暂停确认。
5. 再次训练时双击 `RESUME_C3_TRAINING.bat`。
6. 三个随机种子全部完成后双击 `PACK_C3_RESULTS.bat`，仅将生成的结果 ZIP 带回本机。

## 8. 当前边界

本阶段已完成迁移包构建和本机离线验收，没有在本机 8 GB GPU 上启动完整 C3 训练。真实 batch、吞吐量、预计总时长和最终精度需要在目标 24 GB GPU 首次启动后由自动调优与训练结果确定。
