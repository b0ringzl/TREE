## 论文要求与本地策略边界

WHU-STree 论文附录明确说明：分类基线从完整场景中提取已标注单树，并将每棵树均匀下采样到 8192 点。论文没有说明以下实现细节：

- 少于 8192 点时如何补齐；
- “均匀”具体是随机均匀、空间均匀还是 FPS；
- 是否以及如何做全局坐标归一化。

因此 A3 使用可复现的本地基线策略：

1. 点数不少于 8192 时，以固定种子从点记录中均匀随机无放回采样。
2. 点数少于 8192 时，先保留全部原点，再均匀随机有放回补齐并打乱。
3. 对采样结果做质心中心化，再按最大欧氏半径缩放到单位球。
4. 同时保存原始采样坐标、归一化坐标、采样索引、质心和尺度，因此可恢复坐标或更换预处理策略。

以上补齐与归一化方式是本项目的显式复现选择，不冒充论文未公开的原始代码。

## 实现内容

新增 `src/tscmdl_whu/instances.py`：

- 分块扫描正 tree ID、点数、标签直方图和三维边界。
- 将 float64 tree 字段严格校验为整数后再转换。
- 检测同一 tree ID 是否出现多个物种标签。
- 区分背景 tree 0、无标签实例 label -1 和有效分类实例。
- 保留原始 label；原始 label 0 至 17 保持不变，大于 17 映射到基准 `Others=18`。
- 根据统计点数预分配内存，第二次分块扫描只提取指定实例。
- 提供确定性均匀采样和单位球归一化函数。

新增工具：

- `scripts/profile_whu_instances.py`：生成单轨迹实例清单。
- `scripts/prepare_a3_tree_samples.py`：提取指定实例并生成 NPZ 与清单。
- `scripts/validate_a3_pointmlp_input.py`：验证样本与 8192 点 PointMLP 输入契约。

## 风险与限制

- 只扫描并提取了 `26/1`，尚未验证所有训练轨迹的标签质量。
- 当前“均匀采样”是对点记录做均匀随机抽样，不是 FPS 或体素空间均匀采样。若后续取得官方实现，应以官方策略为准并做消融对照。
- 单位球归一化可能削弱树高和冠幅等绝对尺度信息。原始坐标和变换参数已保留，后续可比较不归一化、仅中心化和单位球三种方案。
- NPZ 保存了 intensity，但当前 PointMLP 冒烟测试只输入 XYZ，与现有 PointMLP 三通道结构一致。
- 原始 label 大于 17 的具体物种名没有完整公开映射，目前只能在 19 类基准中归入 Others。
