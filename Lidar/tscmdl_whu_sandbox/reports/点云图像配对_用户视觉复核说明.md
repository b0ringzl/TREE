# 点云图像配对用户视觉复核说明

## 权限边界

- Codex 视觉预检只用于提前发现明显异常，不能代表用户评价。
- 正式视觉质检必须由用户在本地界面逐样本提交。
- 当前 C1 正式用户质检状态为 `pending`，已评价 `0/38`。
- 未由用户提交的样本不能写成“人工验收完成”。

## 启动方法

双击：

`D:\TREE\Lidar\tscmdl_whu_sandbox\START_USER_VISUAL_REVIEW.bat`

脚本会启动仅本机可访问的网页，并自动打开浏览器。关闭启动脚本的命令窗口或按 `Ctrl+C` 即可停止服务，不会留下训练进程。

正式评价保存在：

`D:\TREE\lidar data\whu\derived\tscmdl\c1_full_shared_dataset\user_visual_review.json`

## 建议质检流程

1. 默认先检查“分层抽检样本”，共 38 棵，每个类别两棵。
2. 在“点云叠加”和“原始裁剪”之间切换，确认红色投影点是否落在目标树上。
3. 选择“通过”“勉强可用”或“不通过”。
4. 对问题样本勾选原因，选择处理动作，并可填写备注。
5. 点击“保存并下一棵”。评价会立即原子写入，不需要等到全部看完才保存。
6. 全部看完后点击“完成当前范围质检”。只要还有未评价样本，系统不会标记完成。
7. 点击“生成处理清单”，或双击 `GENERATE_USER_REVIEW_ACTION_LISTS.bat`。

每次保存、完成范围或导出清单时，C1 `validation.json` 中的用户质检进度也会同步刷新；完整的技术哈希验收不会被重复执行或改写为用户结论。

如果需要逐棵检查全部数据，可将顶部范围切换为“全部 17,134 样本”。抽检范围和全量范围分别记录完成状态。

## 评价标准

| 项目 | 重点判断 |
|---|---|
| 投影对齐 | 红色点云是否主要落在目标树干和树冠上 |
| 目标完整 | 裁剪是否覆盖主要树冠和树干 |
| 目标纯净 | 邻树、车辆、建筑和杆件是否造成明显干扰 |
| 图像质量 | 是否存在严重模糊、过曝、欠曝或目标缺失 |
| 标签可信度 | 图中树木是否疑似与标注树种不一致 |

## 不良数据处理

| 处理动作 | 实际效果 |
|---|---|
| 保留点云与图像 | 样本继续进入点云和多模态派生训练清单 |
| 仅排除图像，保留点云 | 从多模态清单隔离，仍可进入点云训练清单 |
| 改用其他全景视角 | 进入换视角重做队列，当前图像不进入多模态清单 |
| 加入重新裁剪队列 | 进入人工重裁队列，当前图像不进入多模态清单 |
| 整棵排除 | 从点云和多模态两套派生清单排除 |

系统采用非破坏性处理：不删除、不移动、不覆盖原始点云、全景图像或 C1 资产。处理结果只写入新的派生清单，便于复核和回退。

## 输出文件

处理结果位于：

`D:\TREE\lidar data\whu\derived\tscmdl\c1_full_shared_dataset\user_review_outputs`

主要文件：

- `reviewed_samples.csv`：所有已评价样本及用户备注。
- `multimodal_training_manifest.csv`：应用用户决定后的多模态训练清单。
- `point_training_manifest.csv`：应用用户决定后的点云训练清单。
- `multimodal_quarantine.csv`：从多模态清单隔离的样本。
- `rework_queue.csv`：换视角和重新裁剪队列。
- `image_excluded.csv`：仅排除图像的样本。
- `excluded_samples.csv`：整棵排除的样本。
- `review_action_summary.json`：各类处理数量和输出路径汇总。

派生训练清单带有 `review_status` 字段。未评价数据会标记为 `unreviewed`，方便后续按项目要求继续过滤。
