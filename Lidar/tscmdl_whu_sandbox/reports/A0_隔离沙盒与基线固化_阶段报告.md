## 风险结论

1. PointMLP 官方实现依赖旧版 `pointnet2_ops` CUDA 扩展，不能直接装入当前 `yolo` nightly 环境。
2. RTX 5060 需要较新的 CUDA/PyTorch 支持，照搬 PointMLP 原始 Python 3.7、PyTorch 1.10 环境存在显卡架构兼容风险。
3. WSL 当前未安装。A1 应先尝试现代 PyTorch 的原生 Windows 隔离环境和最小扩展验证；若编译失败，再单独请示是否安装 WSL2。
4. D盘余量足够进行环境和小样本验证，但后续派生数据必须设置容量上限。
