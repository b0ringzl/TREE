# TSCMDL 复现阶段门规则

## 执行原则

1. 每次只执行一个已经获得用户批准的小阶段。
2. 阶段结束后必须停止，不自动进入下一阶段。
3. 每个阶段必须在 `reports` 目录生成中文总结报告。
4. 报告必须列出范围、产物、验证结果、风险、磁盘变化和下一阶段动作。
5. 向用户汇报并取得明确同意后，才能更新下一阶段状态为进行中。
6. 原始 WHU-STree 数据保持只读，不移动、不重命名、不覆盖。
7. 不修改 `yolo` 和 `pdf-reading` conda 环境。
8. 不自动执行 `git add -A`、`git add .` 或任何全仓库扫描式 Git 操作。
9. 每个训练阶段必须持续写入标准 `run_config.json`、`training_history.json`、`last.pt` 和 `train.log`，并在启动正式训练前验证 `scripts/monitor_training.py` 可以实时读取。
