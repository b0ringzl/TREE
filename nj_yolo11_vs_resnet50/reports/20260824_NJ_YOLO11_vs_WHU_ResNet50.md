# 南京数据集 YOLO11 与 WHU ResNet50 初步对比

日期：2026-08-24

## 结论

在完全相同的 151 张南京单树裁剪测试图、相同四类标签和相同随机种子编号下，
YOLO11s-cls 的测试 Accuracy 为 **90.0662%**，WHU ResNet50 为 **81.4570%**；
YOLO11s-cls 高 **8.6093 个百分点**。本次配对比较说明 YOLO11 分类骨干在这一固定划分上
表现更好，但 YOLO11 目前只有一个随机种子，因此结果属于初步对比，不能替代三随机种子验收。

## 比较口径

- 任务：已裁剪目标树的四分类，不是整幅街景目标检测。
- 类别：香樟、紫薇、广玉兰、Other。
- 冻结划分：train 6484、val 90、test 151。
- 数据源：WHU D1 四分类正式数据包 `20260817_165127`。
- 无泄漏检查：跨划分图像内容 SHA-256 重复为 0。
- 两模型测试样本逐棵配对，151/151 的 `sample_key` 和真实标签一致。
- 测试目录不向 YOLO 训练器暴露；先按验证集 Macro-F1 选权重，再评估测试一次。

原有十类 YOLO11 检测权重没有用于本比较，因为其类别集合与南京四分类不一致，且检测 mAP
不能与单树裁剪分类 Accuracy 直接比较。本实验使用 ImageNet 预训练 `yolo11s-cls.pt` 新建
南京四分类头并进行迁移学习。

## 模型与训练

| 项目 | YOLO11s-cls | WHU ResNet50 |
|---|---:|---:|
| 参数量 | 5,448,132 | 23,516,228 |
| 输入尺寸 | 224 × 224 | 224 × 224 |
| 预训练 | ImageNet | ImageNet |
| 类别平衡 | 逆频率加权采样 | 平衡采样器 |
| 优化器 | AdamW | SGD |
| 计划轮次 | 100 | 300 |
| 实际轮次 | 39（早停） | 300 |
| 验证选优轮次 | 14 | 280 |
| 本机记录训练时间 | 214.0 秒 | 20,706.1 秒 |

训练时长受 batch size、轮次、优化器、脚本实现和是否恢复训练共同影响，不应把上表时长差
解释为纯架构速度差异。

## 同种子配对结果

| 指标 | YOLO11s-cls | WHU ResNet50 | 差值 |
|---|---:|---:|---:|
| Val Accuracy | 90.0000% | 86.6667% | +3.3333 pp |
| Val Macro-F1 | 89.7640% | 86.1396% | +3.6244 pp |
| Test Accuracy | 90.0662% | 81.4570% | +8.6093 pp |
| Test Balanced Accuracy | 90.4090% | 82.1826% | +8.2264 pp |
| Test Macro-F1 | 89.9768% | 82.2052% | +7.7716 pp |

配对测试结果：两者都对 114 棵、都错 6 棵、仅 ResNet50 对 9 棵、仅 YOLO11s-cls 对
22 棵。Accuracy 配对差值 bootstrap 95% 区间为 **[1.3245, 15.8940] 个百分点**；
McNemar 双侧精确检验 **p=0.02945**。

## 各类测试 F1

| 类别 | YOLO11s-cls | WHU ResNet50 | 差值 |
|---|---:|---:|---:|
| Cinnamomum camphora | 89.4118% | 76.2887% | +13.1231 pp |
| Lagerstroemia indica | 96.8750% | 91.8033% | +5.0717 pp |
| Magnolia grandiflora | 93.0233% | 83.1169% | +9.9064 pp |
| Other | 80.5970% | 77.6119% | +2.9851 pp |

YOLO11s-cls 在四类 F1 上均高于该 ResNet50 run，其中香樟提升最大。`Other` 仍是两个模型
共同最弱的类别，这与它内部包含多个树种、类内差异更大相符。

## 三随机种子解释边界

WHU ResNet50 三随机种子正式结果为 Test Accuracy **75.9382% ± 4.8815%**、Test
Macro-F1 **76.6225% ± 4.9387%**。YOLO11s-cls 本次只有 seed 20260728，不能把一个
YOLO run 与 ResNet 三次均值作同等级稳定性比较。若用于论文或正式模型结论，应继续运行
YOLO11s-cls 的 seed 20260729、20260730，并报告三随机种子均值、标准差和逐树集成结果。

## 解释限制

1. 本结果比较的是单树裁剪分类，不代表 YOLO11 整图自动检测的端到端精度。
2. 两个模型使用各自训练方案：YOLO11 为 AdamW，ResNet50 为 SGD，因此是“完整模型方案”
   对比，不是只替换网络骨干的纯消融实验。
3. 测试集只有 151 棵；统计检验支持当前固定测试集上的差异，但不能替代跨路段、跨城市验证。
4. 同一路段或轨迹的树可能相关，样本级 McNemar 检验把每棵树视为独立，因此 p 值仅作探索性证据；
   正式论文宜补充按道路/轨迹聚类的 bootstrap 或跨路段留出检验。
