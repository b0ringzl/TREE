# SpaceScan Trees 安卓离线测试版

## 这次交付是什么

可安装的原生安卓 APK，不是网页快捷方式。模型随安装包提供，首次启动也不需要下载模型；没有网络权限，不连接电脑或云端服务器。

本版用于验收手机离线流程，**不是当前桌面最佳 BioCLIP 保育模型的等效手机版**。桌面 Demo 和原始权重均保持不变。

兼容目标：Android 8.0 或以上、64 位 ARM 手机/平板；同一个 APK 还包含 x86_64 供模拟器使用。不是 iPhone 安装包，也不支持仅有 32 位系统的旧安卓机。不绑定手机品牌；实体手机尚待验证。

## 安装与第一次验收

1. 把 `SpaceScan-Trees-Offline-v0.1.apk` 通过 USB 等方式复制到手机。
2. 从文件管理器打开 APK。如系统要求，可仅为该文件管理器临时允许“安装未知应用”；无需关闭 Play Protect 等系统安全措施。
3. 打开 SpaceScan Trees，等待“离线模型已就绪”。首次启动会校验模型文件并执行一次真实推理自检。
4. 开启飞行模式并关闭 Wi-Fi，然后从相簿选择本机图片或拍照。
5. 一张图有多棵树时，选择“Polygon crop / 多邊形裁剪”，沿目标逐点点击至少三个顶点，再按“Apply / 套用”。可撤销顶点、取消或还原原图。
6. 检查白色正方形框：它表示模型实际接收的中央范围。按“Identify tree / 辨識樹木”。
7. 查看前三候选、英文学名＋繁体中文、模型分数和质量提示。用“History / 紀錄”查看本机历史，或“Export / 匯出”保存 JSON。

“离线自检”检查实际模型推理和预处理是否与基准一致，不是识别准确率测试。

## 已验证与尚未验证

已在 Android 15（API 35）的本地 x86_64 模拟器中安装、启动；在飞行模式、Wi-Fi 与数据关闭时完成模型自检、本地照片识别、多边形选点/撤销/套用、相机回传、历史记录和 JSON 导出。APK 签名、16 KB ZIP 对齐、模型哈希、无网络权限均已检查。

未在实体 ARM 安卓手机上测试；实际速度、发热、内存和相机厂商差异需要实机确认。模拟器测得的约 0.2 秒不能当成手机速度承诺。

## 识别能力的真实边界

- 模型：既有 YOLO11s-cls 加已锁定的蒸馏分类头，147 个显示类别。本次只导出与适配，没有训练。
- 历史 2,640 张回归图：Top-1 **57.39%**，Top-5 **80.68%**，不是全新街景或手机实拍准确率。尚不满足“桌面最佳识别能力已经完整迁移”的要求。
- 土沉香回归召回率 36.36%（22 张），白桂木 33.33%（6 张），因此不能拿本版替代桌面保育专项展示。
- 同一张土沉香试图在原图输入时排第一；手动裁剪后的试运行误排为印度榕，已在 QA 记录中保留。这说明裁剪能确认目标，但不保证提升该轻量模型的识别准确率。
- 不含点云融合、自动单木检测、全景去畸变，也没有桌面版最新保育专项头。狐尾椰子、红花荷、油杉不在本版输出类别中。
- 榕树标签沿用历史合并输出，显示为 Ficus microcarpa / 榕樹(細葉榕)，不代表已能和 Ficus benjamina 分清。
- 分数是模型相对分数，不等于真实准确率；对清单外物体也可能给出树种候选，不能用作权威鉴定。

## 数据与恢复

本版不附带训练图或参考图库。影像只在本机临时保存；“清空”删除应用内临时照片，不删除相簿原图。历史记录不含照片本体，最多保留 100 次结果。卸载会删除本机记录，请先导出需要的结果。

这是开发签名的本地测试版，不是上架发行版。公开传播模型/上架前仍需审核训练数据权利和开源合规。

预导出备份在主项目 `outputs/SpaceScan_Android_Offline_20260918_v1/pre_training_backup`；交付时再次校验源文件和备份的 SHA-256。本次没有修改桌面模型，因而不需要回滚桌面 Demo。

下一阶段重点：保留这个已跑通的离线外壳，以桌面教师为参考改进移动模型，并在固定数据上证明提升；不要用当前轻量模型的分数冒充桌面教师精度。
