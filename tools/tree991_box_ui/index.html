How to select / 操作

  1. Rotate to locate the trees / 旋轉場景找樹。
  2. Polygon → click vertices around one tree / 多邊形→沿樹輪廓逐點點選。
  3. Double-click / Enter to close; change view and Intersect to trim depth / 雙擊或 Enter 閉合；換視角以「縮小」排除鄰樹。
  4. Inspect isolated selection, save and export / 單獨查看，保存並匯出。

Export is a manual region, not certified clean segmentation. No training or automatic model switch. / 匯出為人工框選區域，仍需清洗及品質核驗；不訓練、不切換模型。
