# SpaceScan Trees — Windows 离线便携版

模型：**SSTv1-H120 · 2026-09-19**。打包日期：2026-09-20。

## 使用方法

1. 将整个 ZIP 复制到另一台电脑，**完整解压**到最终位置，例如 `C:\SpaceScan`。不能在压缩包预览中直接启动。建议短路径，不要放在 Program Files 或无写入权限的位置。
2. 首次双击 `CHECK_COMPUTER.cmd` 检查显卡和文件。已带 Python、PyTorch、CUDA 运行库和模型，不用安装 Python、Conda 或 CUDA Toolkit，也不用联网下载模型。**NVIDIA 显卡驱动仍须由目标电脑安装。**
3. 双击 `START_IMAGE.cmd` 打开单源影像版，或 `START_MULTIMODAL.cmd` 打开可选影像＋点云版。
4. 等待模型载入，浏览器会自动打开本机网址。启动窗口要保持开启；按 Ctrl+C 结束本次运行。只会停止本启动器创建的服务。

首次会修复内置环境的路径。**初始化后不要移动文件夹**；换位置或换电脑时，从原始 ZIP 重新解压一份即可。目标电脑无需管理员权限（安装驱动除外）。请勿同时启动多个副本占用显存。

ZIP 超过 4 GB，U 盘请使用 exFAT 或 NTFS，不能使用 FAT32。一个压缩包同时包含两个入口，不用复制两套模型。

## 硬件边界

- 64 位 Windows 10/11；x86-64 处理器。
- NVIDIA RTX 30/40/50 系列或支持 BF16 的兼容 Ampere 及更新架构显卡；建议 **16 GB 及以上显存**。12 GB 可尝试，但全景多视角／完整检测链路有显存不足风险，未作低显存保证；少于 12 GB 或不支持 BF16 会提示退出，不偷偷换轻量模型。
- 建议 **32 GB 内存**，预留至少 **30 GB 磁盘空间**（同时容纳 ZIP 与解压目录）；首次解压需要较长时间。
- 使用适合本机显卡的较新 NVIDIA 驱动。内置 PyTorch 使用 CUDA 12.8；CUDA 12.8 GA 官方配套 Windows 驱动为 570.65 及以上，不表示所有更旧驱动均不兼容；新显卡可能要求更新驱动。[NVIDIA 官方说明](https://docs.nvidia.com/cuda/archive/12.8.0/cuda-toolkit-release-notes/)
- 本包不是 CPU 版，不适用于 AMD／Intel 独显、Mac 或 ARM Windows。不同显卡可能有小幅数值差异。

## 保留的功能

- 同一版 148 类 H120 图像模型、繁体中文／学名双语候选。
- 上传、粘贴、多边形裁剪、目标树检测、全景透视校正和结果导出。
- 单源影像与影像＋点云两个入口；点云仍是原教师＋PTv2 的**七类**融合，不是 148 类融合。
- 有明确 CC0／CC BY／CC BY-SA 许可记录的原始参考图及其作者、来源、许可链接。参考图仅供比较，不是目标树本身；图像标签不等于独立鉴定。
- 此包保留 293 张、覆盖 147 类的许可参考图；未满足打包许可／署名检查的图片不带入，也不会用训练图补位。分类器仍支持完整 148 类。

## 模型限制

H120 经用户了解取舍后指定部署，并非所有验证指标均提升：固定开发集土沉香正确数 16/22→18/22，误报 7→10；白桂木正确数 10/16→9/16；总体正确数 2304/2650→2302/2650。8 张裁片的 7/8 是训练图片回放，不是独立测试准确率。模型分数不是准确率或已校准概率。

## 数据、许可与排错

- 推理在本机完成，仅绑定 `127.0.0.1`；普通识别不保存上传影像。用户手动保存参考图时会写入本包 `app/external_datasets/spacescan_manual_references_v1`。
- 不包含训练图片、Google 街景、原始点云场景、人审数据库、研究网页或安卓包；旧研究入口已从便携版隐藏。参考图外链需要联网，但识别不依赖网络。
- 保留所有随运行库分发的第三方许可证及源代码；额外说明见 `THIRD_PARTY_NOTICES.md` 和 `licenses`。本交付面向用户的私人本机评估，不是公开发布或商业转售许可。模型底座许可证不自动授予训练照片的传播权。
