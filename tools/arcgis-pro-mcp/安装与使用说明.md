# ArcGIS Pro MCP 安装与使用说明

## 安装状态

- ArcGIS Pro：3.5.2
- ArcPy：3.5.2
- 许可级别：Advanced（ArcInfo）
- MCP Python SDK：1.29.0
- MCP 服务目录：`D:\TREE\tools\arcgis-pro-mcp`
- 独立运行环境：`D:\TREE\tools\arcgis-pro-mcp\.venv`
- Codex 服务名：`arcgis_pro`

MCP 已登记到 `C:\Users\57680\.codex\config.toml`。安装完成后需要重启
Codex，新的任务才能加载 `arcgis_pro` 工具。

## 数据安全边界

1. 输入数据只能位于 `D:\TREE` 下。
2. 输出数据只能写入 `D:\TREE\gis_output`。
3. 已存在的输出一律拒绝覆盖，必须换一个新名称。
4. 几何修复会先复制数据，只修改新副本。
5. 不提供删除数据、任意 ArcPy 代码执行或原位字段修改工具。
6. 每次调用记录在 `logs\tool_calls.jsonl`。
7. 每个 ArcPy 工作者都有看门进程；任务超时、取消或 MCP 服务退出时会清理
   整个子进程树，避免留下后台训练或地理处理进程。

安全范围可在 `config.json` 中调整，修改后需要重启 Codex。

启动多个实例；日常使用由 Codex 自动启动和关闭。
