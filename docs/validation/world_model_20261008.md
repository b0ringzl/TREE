# 桌面 Demo：原始 BioCLIP 广域植物与范围提示

日期：2026-10-08。没有训练、拟合分类头、解冻或蒸馏；没有替换任何已有模型权重。

## 功能

- 默认“香港常见树木 · SST”，保留原来的 148 个原始输出与 146 个展示类别。
- 可手动选择“广域植物 · 原始 BioCLIP”。使用同一套未修改的 BioCLIP 2.5 图像编码器和与该模型匹配的官方 TreeOfLife 文本特征，筛选并去重 Plantae 后为 348,967 个植物目录条目。不是 348,967 个物种均已验证准确识别，也不是地球所有植物。
- 香港范围每次识别增加一次独立广域检查。达到范围提示条件时，显示“可能不在香港常见树木范围内”，用户可以查看本次同一目标裁片的广域候选，再返回原 SST 结果。不会自动换模型、混合两模型分数或提高分数。
- SAM 紧裁片继续单次全裁片推理，广域分支也不再加中心细节投票；普通照片的广域分支以全图与中心细节的原始 logits 等权平均。
- 双源点云、影片和走廊的原识别／跟踪流程不变；本次新增的是桌面照片入口的识别范围，不包括安卓版同步或重新打包离线便携版。

## 提示条件（试用规则，不是 PlantNet 的私有阈值）

1. 广域首位候选不在香港目录内。
2. 该候选的属也未在香港目录覆盖的属中；同属近似种暂不作强范围判断。
3. 全图与中心细节的广域首位候选属一致；SAM 单次路径只有一个视图。
4. 在同一广域目录内，最佳目录外候选的 logit 比最佳目录内候选至少高 2.0。
5. 没有已有暗图、过曝或细节不足警告；低质量优先提示补图。

SST 首位分数低于 14% 且没有更强的范围证据时，提示暂不能确定、更换角度或补充近照，并提供广域入口。低 SST 分数本身不是“目录外物种”的证据。无需 SST 低分才能触发范围提示：封闭目录也可能对目录外植物错误地打出高分。

4 张未触发强范围提示的目录外照片是同属近似种：欧洲赤松和蓝桉各 2 张；可手动使用广域范围。广域首位错误的 3 张为向日葵、欧洲栎和垂枝桦的近似种混淆。香港组误提示为 Vernicia montana，被广域模型排为 Firmiana simplex；原 SST 结果没有被替换。详见 `audit_results.json`。

测试标签来自 iNaturalist research-grade 源记录，不是独立专家重新鉴定。既有香港图片是已观察过的回归集；新公共图片也可能进入基础模型预训练。以上不能作为整体开放集精度或 34.9 万条目的准确率。香港组广域模型明显弱于专门适配的 SST，因此 SST 保持默认。

## PlantNet 实测

公开 CC0 湿地松照片（photo 536744118），不提交任何贡献：

- “欧洲作物”（221 种）下没有强行输出作物候选；显示“另一份植物志（世界植物区系）中已检测到一种相似物种（Pinus elliottii Engelm.）”，并提供重新识别按钮。
- 点击按钮到世界植物区系，首位湿地松为 50.5%（结果卡四舍五入显示 50%），没有范围切换提示。
- 区系内对照：番茄 CC0 叶片照片（photo 1620958）放在“欧洲作物”下，首位番茄为 50.8%（结果卡显示 51%），没有换区系提示。两者约 50% 的分数相近，但是否提示不同。

这说明至少该案例的触发依据是其他目录存在相似候选，而不是简单的低分阈值。PlantNet 的内部具体阈值未公开，不能由少数例子反推出准确公式。

资料：[PlantNet 区系说明](https://docs.plantnet.org/en/tutorials/choose-a-flora/)、[识别页面](https://identify.plantnet.org/zh/k-world-flora/identify)、[BioCLIP 官方文本特征说明](https://huggingface.co/datasets/imageomics/TreeOfLife-200M/blob/main/embeddings/README.md)。官方文件固定到 revision `5f2dc493b3dc0e544438a04038ab15faa646b749`，完整下载源与派生文件均记录并校验 SHA-256。

权重、原部署标签与 release.json 均不变；仅修改网页和推理服务代码，并新增独立广域植物特征包。备份校验与正式运行检查见 `deployment_gate.json`、`live_acceptance.json`。
